## 在架分装（repack）

`POST /api/split {lot_id, qty}` 把一个在架母批拆出 `qty` 成为新子批（`lots.parent_id` 指向母批）。

- 预览只发生在前端，确认前不调用接口、不改余量；确认后 `子批 + 母批余量 == 拆前余量`。
- 母批必须存活（拆量严格小于余量）：拆量为零、为负或 ≥ 余量时整单 4xx 失败并回到拆前，不留没有母批的孤儿子批。
- 拆批资格与消费候选同一套：`status='on_shelf'` 且 `qty_remain>0` 且 `data_quality='clean'`。脏批、负余量行不能拆也不能被消费。
- 同到期日 FEFO 优先扣子批行，避免扣到已经拆没的母批 id；更早到期日的其他批次仍优先。
- 操作同事务（插入子批 + 扣减母批），异常回滚；`consumptions` 只记录当次实际扣减，拆批不回放假想履历，历史中记下的母批 id 不会在子批上再扣一遍。
- 全层页与层页均可发起分装；两页对同层按商品的加总一致，分装前后总量不变。
